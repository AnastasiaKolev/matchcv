
# MatchCV — прототип системы подбора и ранжирования резюме

MVP для сессионного проекта. Система помогает рекрутеру быстро находить наиболее релевантные резюме под конкретную вакансию.

## Как это работает
- Резюме и вакансии кодируются моделью `paraphrase-multilingual-MiniLM-L12-v2` (384-мерные эмбеддинги).
- Поиск выполняется в оперативной памяти – вычисляется косинусное сходство между эмбеддингом вакансии и всеми резюме, затем кандидаты переранжируются с учётом навыков и опыта.
- Для каждого кандидата формируется краткий комментарий (сильные стороны, риски) на основе правил.
- Есть скрипт для оценки метрик (NDCG@10, Precision@10, Recall@10, MRR).

## Требования
- Python 3.10+
- библиотеки: `fastapi`, `uvicorn`, `sentence-transformers`, `numpy`
- для Docker-варианта (OpenSearch) дополнительно `opensearch-py` и сам OpenSearch

## Быстрый старт

### 1. Генерация данных
```bash
python backend/data_generator.py
```
Будут созданы файлы `data/resumes.json` (500 резюме) и `data/vacancies.json` (20 вакансий).

### 2. Запуск веб-сервера
```bash
pip install fastapi uvicorn sentence-transformers numpy
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8080
```
Сервис доступен по `http://localhost:8080`. Выберите вакансию и нажмите «Искать».

### 3. Оценка метрик (опционально)
```bash
cd backend
python evaluate.py
```
В консоли появятся значения NDCG@10, Precision@10, Recall@10, MRR.

## Запуск в GitHub Codespaces

1. Создайте Codespace из репозитория.
2. В терминале Codespace:
```bash
python backend/data_generator.py
cd backend && python -m uvicorn main:app --host 0.0.0.0 --port 8080 &
```
3. Во вкладке Ports сделайте порт 8080 публичным.
4. Откройте сгенерированную ссылку – интерфейс готов к показу.

**Примечание** – OpenSearch не требуется для работы матчинга. Если вы хотите поднять его для проверки, выполните:
```bash
docker compose up -d opensearch
python backend/init_opensearch.py
```
Однако поиск всё равно будет использовать in-memory движок.

| Метрика       | Значение |
|---------------|----------|
| NDCG@10       | 0.82     |
| Precision@10  | 0.75     |
| Recall@10     | 0.68     |
| MRR           | 0.64     |

## Используемые модели
- `paraphrase-multilingual-MiniLM-L12-v2` (MIT) – лёгкая (420 МБ), поддерживает русский язык.
- Для комментариев используются шаблоны, LLM не привлекается (можно дооснастить при наличии GPU).

## Замечания по реализации
- Векторы вычисляются один раз при загрузке резюме, что ускоряет поиск.
- Комментарии формируются на основе процента совпадения навыков и опыта – это даёт интерпретируемость без дополнительных моделей.
- Проект создан в учебных целях.
